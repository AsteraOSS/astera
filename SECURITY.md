# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The Astera security team takes the security of our developer tools very seriously.

If you discover a security vulnerability within Astera Studio, please do **NOT** open a public GitHub issue. Instead, submit a security report directly to our security team via email at **security@astera.dev**.

### What to include in your report:
- Type of issue (e.g., secret disclosure, XSS, prototype pollution)
- Detailed steps to reproduce the vulnerability
- Proof of concept payload if applicable
- Affected component or API surface

You will receive an acknowledgment response within 24 hours, and we aim to release a patch within 72 hours of confirmation.
